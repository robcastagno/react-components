# React Components
- Project is for testing and building small UI components to be used across other projects

# Current Components
- Button
  - Variants (Primary, Secondary, Danger, Invalid, Success, Warning)
  - Sizes (Small, Medium, Large)
  - Radius (None, Small, Medium, Large, Full)
  - Disabled State

# In-Progress Components
- Virtual Scroller
  - Can scroll through a large list of values with memory of what items belong where
  - Horizontal scrolling (not implemented)
  - Size awareness (not implemeneted)
